# 🔮 Projeto Signo Zodiacal

Projeto desenvolvido em **HTML, CSS, JavaScript e Bootstrap** para descobrir o signo do usuário de acordo com a data de nascimento.

## 📌 Funcionalidades

- Inserção da data de nascimento
- Identificação automática do signo zodiacal
- Exibição do nome do signo
- Pequena descrição de características
- Interface moderna e responsiva
- Estilização com Bootstrap + CSS próprio

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
